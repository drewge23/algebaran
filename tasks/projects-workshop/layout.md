# Projects — layout

## Mobile (390 × 844)

```text
top bar: Projects / REACH ALGEbaran / π

                stage rocket art
           2 / 5 systems assembled
                6 / 15 missions

              CURRENT MISSION
         title · story · objective · reward
                 START MISSION

                 BUILD STAGES
          Hull · Fuel · Engine · Navigation · Launch
```

The rocket owns the visual focus. The mission card gives the next action without
competing with it. Stage tiles show only glyph, stage name and progress.

## Larger viewports

Keep a narrow reading column. Increase the rocket’s available breathing room
and tile width rather than putting the workshop in a side panel or creating a
dense grid.
